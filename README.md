# NexusAI

A multi-page web dashboard for monitoring edge AI chips, robot controllers and sensors in real time.
Built with plain HTML, CSS and JavaScript as a first-semester B.Tech web development project.

## Pages
- **Home**: overview, live preview card, feature links
- **Dashboard**: simulated live telemetry, graph, node switches, load spike, event log
- **Components**: hardware gallery with search, filters, sorting, favourites and spec popup
- **Roadmap**: four growth phases with a task checklist and progress bar
- **Team**: flip cards and a contact form with validation

## Run
Open `index.html` in a browser. Internet is needed for the fonts and icons.

## Tech
HTML5, CSS3 (Flexbox, Grid, media queries), vanilla JavaScript, Canvas API, Font Awesome.
